# 🎓 杨宇欣的 Math Sprint - 2026考研数学一专属冲刺系统

> **“稳住心态，一战成硕。”**  
> 专为 **杨宇欣同学** 打造的考研数学冲刺辅助系统，集每日一练、心态调节与 AI 智能辅导于一体。

## ✨ 主要功能

### 1. 📝 2026 预测·每日一练
精选 **高数、线代、概率论** 核心考点预测题。
- **题眼点拨**：不仅有标准解析，更有针对性的核心考点提示。
- **随机抽题**：每次刷新或切换，随机呈现不同题目，保持新鲜感。

### 2. 🤖 Gemini 备考急救室
内置 Google Gemini AI 模型，作为你的专属全天候陪考导师。
- **智能解惑**：遇到焦虑复习不完？不知道如何规划最后几天？输入你的困惑，获取“靠谱学长”般的急救建议。
- **信心点拨**：针对具体题目，让 AI 分析题眼并给予信心鼓励。

### 3. ❤️ 考场心态 & 信心加油站
- **信心语录**：随机切换的鼓励话语，驱散考前焦虑。
- **备考锦囊**：从作息调整到应试策略，提供科学的考前建议。

## 🚀 如何使用

本项目为纯静态单页应用，无需复杂的环境配置。

1. **下载项目**：Clone 或下载本项目压缩包。
2. **获取 API Key**：
   - 本项目依赖 Google Gemini API。
   - 打开 `index.html`，找到第 **181** 行：
     ```javascript
     const apiKey = "YOUR_API_KEY_HERE"; 
     ```
   - 填入你有效的 Gemini API Key。
3. **运行**：双击 `index.html` 在浏览器中打开即可开启冲刺之旅！
